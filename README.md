# vnmap

[![R-CMD-check](https://github.com/ura8107/vnmap/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/ura8107/vnmap/actions/workflows/R-CMD-check.yaml)

`vnmap` makes publication-ready choropleth maps of Viet Nam in R. It follows
the compact API of [`usmap`](https://usmap.dev), while accounting for Viet
Nam's July 2025 administrative reform.

## Installation

Install the current development version directly from GitHub with either
`remotes` or `pak`:

```r
# Using remotes
install.packages("remotes")
remotes::install_github("ura8107/vnmap")

# Or, using pak
install.packages("pak")
pak::pkg_install("ura8107/vnmap")
```

The repository must be public for anonymous installation. For a private
repository, set a GitHub personal access token before installation, for
example with `Sys.setenv(GITHUB_PAT = "...")`.

## Quick start

```r
library(vnmap)
library(ggplot2)

plot_vnmap()

example <- data.frame(
  province = province_info()$name_en,
  value = seq_len(34)
)

plot_vnmap(data = example, values = "value", id = "province",
           color = "white", linewidth = 0.2) +
  scale_fill_viridis_c()
```

## Administrative geographies

The current 34-unit geography is the default. The 63-unit geography used
immediately before 1 July 2025 remains available for historical data.

```r
vn_map()                              # 34 current units as an sf object
vn_map("provinces_63")               # historical 63-unit geography
plot_vnmap(include = c("Hà Nội", "Bac Ninh"))
province_code(c("Đà Nẵng", "Da Nang", "Danang"))
province_info("79")
```

Identifiers accept official two-digit administrative codes and names with or
without Vietnamese diacritics. `province_info()` provides a clean join table.

## Data provenance

The bundled geometry is derived from the public-domain
[geoBoundaries VNM ADM1 release](https://www.geoboundaries.org/), generalized
for plotting. The current geography is generated by dissolving the former
provincial boundaries according to Viet Nam Decision 19/2025/QD-TTg, effective
1 July 2025. The
[`data-raw/`](https://github.com/ura8107/vnmap/tree/main/data-raw) directory
contains the complete reproducible build.

Because the source boundary vintage is 2008, this package is intended for
statistical visualization rather than surveying, navigation, or adjudicating
territorial claims.
