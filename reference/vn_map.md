# Obtain Viet Nam map data

Returns a simple-features boundary layer for the provincial-level
administrative units of Viet Nam. The current layer contains the 34
units effective from 1 July 2025. A 63-unit layer is retained for data
collected under the immediately preceding geography.

## Usage

``` r
vn_map(
  geography = c("provinces", "communes", "provinces_63", "districts_63", "communes_63"),
  include = NULL,
  region = NULL,
  province = NULL,
  crs = vnmap_crs()
)
```

## Arguments

- geography:

  One of `"provinces"` (the 34 units effective from July 2025),
  `"communes"` (current commune-level units), `"provinces_63"` (the
  pre-July 2025 units), `"districts_63"` (the pre-July 2025
  district-level units), or `"communes_63"` (the pre-July 2025
  commune-level units). See Details for the optional lower-level layers.

- include:

  Optional character vector of names, aliases, official two-digit codes,
  or ISO 3166-2 codes to retain. Vietnamese names may be supplied with
  or without diacritics.

- region:

  Optional character vector of socio-economic region codes (`"RRD"`,
  `"NMM"`, `"NCC"`, `"CH"`, `"SE"`, `"MRD"`) or English region names
  used to retain whole regions. Units matching either `include` or
  `region` are kept. Available only for the provincial geographies.

- province:

  Optional character vector of provincial-level identifiers (names,
  aliases, or codes) used to keep only the lower-level units that fall
  inside those provinces. Available for `"communes"`, `"districts_63"`,
  and `"communes_63"`; historical layers resolve against the 63-unit
  geography.

- crs:

  Coordinate reference system understood by
  [`sf::st_transform()`](https://r-spatial.github.io/sf/reference/st_transform.html).

## Value

An `sf` object with one row per unit. Provincial layers carry `code`,
`iso`, `name_vi`, `name_en`, `type`, and `geometry`; current units
created by the 2025 reform have `NA` in `iso` where no code is bundled.
The lower-level layers carry `code`, `name_vi`, `name_en`,
`province_code`, `province_en`, and `geometry`.

## Details

The bundled geometry is projected to EPSG:3405 by default. Pass a
different EPSG code or an `sf` CRS object to `crs` when another
projection is required. Filtering happens before transformation.

The current 34-unit layer is dissolved from the exact same current
commune source described below, so parent and child boundaries share the
same 25 July 2026 observed snapshot. Historical `"provinces_63"`
geometry remains derived from geoBoundaries. All geometry is intended
for statistical graphics, not surveying, navigation, or legal
determinations.

The bundled `"communes"` layer contains the 3,321 current commune-level
units in the 25 July 2026 catalogue snapshot. It carries validity,
geography-vintage, source, and geometry-accuracy columns. Its boundaries
are generalized to 100 metres for statistical graphics.

The optional `"districts_63"` (second-level) and `"communes_63"`
(third-level) layers hold the district and commune units as they existed
before the July 2025 reform, which abolished the district tier and
merged communes. They are historical only, are not bundled by default
because of their size, and are generated by `data-raw/build_adm2.R` and
`data-raw/build_adm3.R`; `vn_map()` raises an informative error when the
requested layer has not been built. The commune layer contains many
thousands of units, so filtering with `province` (or `include`) is
strongly recommended rather than drawing it nationwide.

This function requires the sf package. Name and code lookups
([`province_code()`](https://ura8107.github.io/vnmap/reference/province_code.md),
[`province_info()`](https://ura8107.github.io/vnmap/reference/province_info.md),
[`province_region()`](https://ura8107.github.io/vnmap/reference/province_region.md))
work without it.

## Examples

``` r
map <- vn_map()
nrow(map)
#> [1] 34
names(map)
#>  [1] "code"              "iso"               "name_vi"          
#>  [4] "name_en"           "type"              "geometry"         
#>  [7] "geography_vintage" "source_url"        "snapshot_date"    
#> [10] "observed_on"       "geometry_accuracy"

north <- vn_map(include = c("Ha Noi", "Bac Ninh"))
nrow(north)
#> [1] 2

delta <- vn_map(region = "MRD")
nrow(delta)
#> [1] 6

historical <- vn_map("provinces_63", crs = 4326)
sf::st_crs(historical)$input
#> [1] "EPSG:4326"

if (FALSE) { # \dontrun{
# Lower-level layers must be built first (see data-raw/build_adm3.R).
hanoi_communes <- vn_map("communes_63", province = "Ha Noi")
} # }
```
